## `03` / Selected builds

### 🛡️ Kavach.ai — Malware Analysis & Threat Triage

**1st Place · GajShield / KJSCE Hack 8**

A cybersecurity desktop suite that analyses suspicious binaries without trusting them.

- Isolated, disposable Docker sandboxes for malware analysis.
- Static entropy analysis, dynamic syscall-rule flagging, and an XGBoost classifier trained on approximately 184 GB of malware byte data.
- LLaMA 3.2 translates technical telemetry into human-readable security verdicts.

`Python` `Electron.js` `Docker` `XGBoost` `LLaMA 3.2`

### 💸 FinSaathi — AI-Powered Financial Intelligence

**1st Place · Datathon 24**

Financial guidance, government-scheme discovery, document intelligence, and personalised recommendations brought into one platform.

- RAG and hybrid search for matching users to government schemes.
- Reported approximately 94% matching accuracy across eight languages and a catalogue of 200+ schemes.
- Includes financial-document processing and a multilingual WhatsApp assistant.

`Next.js` `Python` `Flask` `PyTorch` `Sentence Transformers` `Twilio`

### 🌐 LoanSaathi — Multilingual AI Loan Assistant

**1st Place · Great Bengaluru Hackathon**

A multilingual assistant designed to make complicated loan paperwork less intimidating.

- Extracts loan documents using OCR and identifies potentially predatory clauses.
- Combines Mistral Saba 24B and fine-tuned FinLLaMa for document understanding and financial guidance.
- Supports eligibility checks, EMI calculations, and eight Indian languages.
- Implements ephemeral session workflows to discard processed documents after completion.

`FastAPI` `Next.js` `Mistral` `FinLLaMa` `PaddleOCR` `Supabase`

### 🌊 SeaGuard — Maritime Safety & Fishing Intelligence

**Most Product Readiness · Hackcelestial 2.0**

A mobile assistant for fishermen that combines Potential Fishing Zone predictions with practical safety tools.

- Reported approximately 97% PFZ prediction accuracy using satellite and weather telemetry.
- Adds SOS alerts, GPS-based maritime-boundary warnings, trip support, and multilingual voice access.
- Exhibited to the Chairman of ISRO in 2025.

`React Native` `FastAPI` `TensorFlow` `Python` `Supabase`

### 🧠 Intelligent Cooperative Q&A Agents

**2nd Runner-Up · AMD AI Sprint, IIT Bombay**

Two cooperating models, one constrained GPU environment, and 24 hours to build.

- Fine-tuned Qwen-3 4B to generate challenging domain-specific questions.
- Built a LLaMA 3.2 3B answer agent using multi-pass verification.
- Achieved approximately 10-second question generation and 6–7-second answer latency under the competition setup.

`PyTorch` `Qwen-3` `LLaMA 3.2` `SFT` `Synthetic Data`

## `06` / My engineering philosophy

> A demo proves that something can work. Engineering proves that it keeps working.

- **Automate the boring.** Humans should spend less time moving data between systems and more time making decisions.
- **Measure the outcome.** Latency, accuracy, reliability, and time saved beat vague claims about innovation.
- **Treat AI as a system.** Retrieval, data quality, evaluation, interfaces, and failure handling matter just as much as the model.
- **Ship, learn, iterate.** The first version is a starting point, not a victory lap.
